# Datara

*A universe of expertise. Working for you.*

Datara is a persistent personal data home that applies reusable expertise to validated datasets through the user's chosen AI model. Structured results are available through a predefined dashboard and an output API.

## Project status

Project foundation documented. Implementation has not started.

## First release

- Manual uploads of supported Garmin `.fit` files.
- Deterministic validation, normalization, and preprocessing.
- Datara-created baseline skills with explicit input eligibility.
- Analysis using the user's own model API access.
- Persistent results with evidence and execution history.
- Predefined dashboard and authorized read-only output API.

## Planning

See [Project brief and roadmap](docs/project-brief-and-roadmap.md) for P0 requirements, acceptance criteria, user stories, responsibility boundaries, and phased delivery.

AI skill recommendations and automatic routines follow at P1. Source-to-skill tooling, expert creator tools, and additional domains are later stages. Commercial design is deferred.
