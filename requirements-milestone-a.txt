# DATARA Milestone A pinned dependency set.

# Scope: the single pinned install/run/test command `scripts/milestone_a.sh`
# (G0 replacement criterion 5, decision-register.md:51).
#
# Pins are exact `==` for every distribution in the resolved set, including the
# transitive ones, so the inventory is fully reproducible. No per-file hashes are
# recorded: `psycopg-binary` publishes platform-specific wheels (win_amd64,
# manylinux, macosx), so committing Windows-only artifact hashes would make this
# file unusable on the Linux container reference topology (D05). The
# reproducibility token used by the pinned command is therefore the SHA-256 of
# *this file*, printed as `pinned_dependency_lock_sha256`. Any change to any pin
# changes that value.
#
# D05 selects Django 5.2 LTS and PostgreSQL 17. `psycopg[binary]` is the
# PostgreSQL 17 driver.
#
# `typing_extensions` is a transitive dependency of **psycopg** (its marker is
# `typing-extensions>=4.6; python_version < "3.13"`) and was ABSENT from this file
# while being installed. Django does NOT require it: Django 5.2.17 declares only
# asgiref, sqlparse and tzdata. That made the claim above -- "exact == for every
# distribution in the resolved set, including the transitive ones" -- false: an
# unpinned transitive dependency resolves differently per environment while still
# satisfying this file. Pinned at the version present in the verified environment.
# See docs/management/pinned-environment-decisions-2026-10-05.md.
# NOTE: adding this line changes `lock_sha256`, which is the SHA-256 of this file.
# Evidence quoting the previous value is not comparable.
#
# No *model-provider* SDK is pinned: Milestone A makes no provider call (SR06),
# and G0 criterion 3 is explicitly not waived for a provider. Nothing here may be
# read as evidence that a provider is usable from China.
#
# `garmin-fit-sdk` IS pinned, and the distinction matters -- do not "tidy" it out
# on the strength of the paragraph above. A model-provider SDK is a *remote model
# service client*: calling one is a network call to a third party and is exactly
# what G0 criterion 3 withholds. `garmin-fit-sdk` is a **file-format decoder**:
# a pure-Python local library that parses the FIT container, supplies the
# profile constants and computes the FIT CRC. It contacts nothing. D01 selects the
# official FIT decoder as the conformance basis, TK10's matrix is recorded
# against profile 21.217.0, and `datara/classification.py` reads its profile
# constants and cross-checks its CRC. Without the pin, every TK11 case fails
# `decoder_unavailable` and the suite reports a *rejection* where a *decode* was
# required -- a green run that proved nothing. An absent decoder must be a
# declared deviation, not a silently skipped capability.
#
